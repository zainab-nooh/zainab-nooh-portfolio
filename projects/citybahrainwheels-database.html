Objective

What the project set out to do

Design a database that can actually run a ride-hailing service at scale — resolving the many-to-many relationships between drivers, passengers, and promotions cleanly, while accounting for data protection law.

My Contribution

What I actually built

I co-designed a 12-entity Context and Physical ERD. I resolved multi-valued attributes and many-to-many relationships (driver-to-passenger, passenger-to-promotions) using optimized junction tables to eliminate redundancy. I wrote complete DDL/DML scripts and advanced multi-table JOIN queries with aggregation to extract driver earnings, ride status, and feedback analytics.
