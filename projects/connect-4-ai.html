Objective

What the project set out to do

Build a genuinely playable game from scratch — clean state management, real win-condition logic in all directions, and an opponent that adapts rather than plays randomly.

My Contribution

What I actually built

I built the full game solo: modular JavaScript state management, gravity-based piece placement, and a zero-overhead game loop detecting vertical, horizontal, and diagonal four-in-a-row connections across a 2D array. I deployed the finished build to Render with Git-managed version history.
