Objective

What the project set out to do

Build a working Security Operations Center that doesn't just collect alerts, but automates the triage work analysts normally do by hand — pulling context on indicators the moment an alert fires, instead of hours later.

My Contribution

What I actually built

I owned the SOAR engineering end to end using Shuffle. I built the automation playbooks that ingest alerts directly from Wazuh via dynamic webhooks, wrote the logic to pull indicator data — file hashes, suspicious IPs — out of raw alert payloads, and orchestrated API integrations against VirusTotal and AbuseIPDB to enrich those indicators automatically. I also built the routing logic that turns a raw SIEM alert into a contextual, intel-backed notification for an analyst.
