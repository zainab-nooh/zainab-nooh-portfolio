Objective

What the project set out to do

Replace the scattered process of planning an event — separate vendors for equipment, services, and scheduling — with a single platform covering the whole booking lifecycle.

My Contribution

What I actually built

I built the full-stack platform using Node.js/Express.js and Mongoose/MongoDB for data, with JWT-based authentication. I implemented the booking and rental logic covering equipment and service reservations, and worked on the seamless end-to-end user experience across event types.

Evidence

Live hosted interface, booking and rental flow screens, database schema diagrams for events/bookings, and API endpoint route maps.
