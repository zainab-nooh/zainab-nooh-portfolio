Objective

What the project set out to do

Go beyond classifying known attacks — build a framework that can also flag statistically anomalous traffic it's never seen labeled before, using unsupervised learning alongside a supervised classifier.

My Contribution

What I actually built

I co-developed the preprocessing, multi-model evaluation, and interpretability pipelines across 21,185 network flow entries. I engineered a clean feature space, stripping non-predictive identifiers and pruning 25 redundant dimensions down to 54 critical behavioral fields via correlation analysis. I set up a balanced multi-class XGBoost classifier to counter class imbalance, and built Isolation Forest and K-Means pipelines to detect statistical anomalies and profile traffic behavior without relying on labels.
